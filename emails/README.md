# Invitation emails

| Wave | Sent by | Through | Subject | Audience |
|---|---|---|---|---|
| First | The featured label | The label's own mailing system | The label's choice | The label's past customers |
| Second | Orvel | Orvel's list (`MAILING_PROVIDER`, tag `wave-2`) | **An invitation from Orvel** | Everyone who joined via /invitations |

`second-invitation.html` is the template for the second wave. It is not sent automatically: send it as a campaign from the provider once the label has approved the preview and the schedule, after the first wave. Booking (the confirmed place) is a separate system that is not part of this site yet.
